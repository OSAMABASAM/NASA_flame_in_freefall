# Claude Code على المتصفح للمبتدئ: كل اللي بتحتاجه

## شو هو؟
تخيّل عندك مبرمج شاطر شغّال على كمبيوتر بالسحابة. بتعطيه مشروعك من GitHub وبتحكي معه بكلام عادي. هو بيكتب الكود، بيشغّله، وبيرجعلك التعديلات على GitHub. أنت ما بتنزّل ولا شي على جهازك.

| الحساب | ليش |

| GitHub | هون بيعيش الكود |

## الشاشة بكلمتين
- **صندوق الرسالة:** بتكتب فيه طلبك، مثلاً `/hack-build Task 0`.
- **اختيار الـ repo:** فوق، بتختار المشروع `flame-in-freefall`.
- **الموديل:** Opus للتفكير الصعب، Sonnet للتنفيذ وأرخص.
- **زر Create PR:** لما Claude يخلص، التعديلات بتكون بفرع جانبي (branch). الزر بيعمل طلب دمج (Pull Request)، وأنت بتدمجه على github.com بزر **Merge**. بعد الدمج Vercel بينشر لحاله. إذا ما لقيت الزر، اكتب لـ Claude: «Create a pull request to main».
- **قائمة الجلسات على اليسار:** كل مهمة بجلسة جديدة.

## الأوامر اللي بتحتاجها

| توقفه وهو شغّال | زر الإيقاف (Stop) أو `Esc` |
| قائمة السكلز | اكتب `/` |

## 5 قواعد بتوفّر وقتك ورصيدك
1. **مهمة وحدة بكل جلسة.** خلصت؟ اعمل PR، ادمجه، وافتح جلسة جديدة للمهمة اللي بعدها.
2. **كن محدد.** «صلّح زر البحث بالصفحة الرئيسية» أحسن من «صلّح الموقع».
3. **افحص بعينك بعد كل دمج.** افتح الرابط الحي وجرّب. Claude ممكن يقول «خلصت» وهو مش خالص.
4. **ما تفهم شي؟ اسأله.** «اشرحلي شو عملت بكلام بسيط». هيك بتقدر تجاوب الحكام.
5. **إذا علق نص ساعة على نفس الخطأ:** `/diagnosing-bugs`. وإذا ضل عالق: «بسّطها أو احذفها».
